# Kit · tu propio Paperflow

Documentos para construir una versión personal de Paperflow en otro computador, con Claude Code, adaptada a la forma de trabajar de quien la use.

| Orden | Archivo | Para qué |
|---|---|---|
| 1 | `00-PROMPT.md` | **Empieza aquí.** Cómo usar el kit y el prompt para pegar en Claude Code |
| 2 | `PRD.md` | Qué es el producto, para quién y qué debe hacer |
| 3 | `DESCUBRIMIENTO.md` | Las preguntas sobre tu forma de trabajar → `MODELO.md` |
| 4 | `MODELO-NOTION.md` | Cómo se modela el trabajo en Notion y cómo se crea |
| 5 | `BLUEPRINT.md` | Arquitectura, API, seguridad y flujos |
| 6 | `DESIGN.md` | Sistema visual, componentes, sonidos y accesibilidad |
| 7 | `PLAN.md` | Fases con criterios de "listo" |
| 8 | `DESPLIEGUE.md` | Cuentas, secretos y publicación paso a paso |
| 9 | `CLAUDE.md` | Reglas para Claude Code (copiar a la raíz del repo) |

**Idea central**: la plataforma no impone un método. La fase de descubrimiento define cómo se llaman y cómo se comportan los grupos de trabajo, las tareas y los estados. Todo eso queda en `MODELO.md`, y de ahí sale lo que se crea en Notion y lo que muestra la app.
